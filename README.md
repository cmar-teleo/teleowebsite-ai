# TELEO Capital website

Next.js (App Router) + TypeScript + Tailwind CSS v4, with GSAP ScrollTrigger and Lenis for scroll choreography. Exported as a static site.

Concept: **Telos, the completed arc.** A dark, cinematic site whose Greek imagery is painted, not modelled: dark-ground fresco in mineral pigments, separated into layers and moved in depth by scroll.

## Run it

Requires Node 20 or newer.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # static export to ./out
npm run start      # serve ./out locally
npm run paint      # repaint the fresco plates into public/plates
npm run og         # regenerate Open Graph images into public/og (uses the plates)
npm run typecheck
```

Deploy the `out/` folder to Cloudflare Pages or any static host. Build command `npm run build`, output directory `out`, `NODE_VERSION` 20.

## The fresco plates

Every Greek image is a painted plate in `public/plates/`, in one language: dark-ground fresco. Vine-black plaster, mottled and cracked; chalk white, yellow ochre and red ochre laid on in visible brush strokes; a dull earth green and a rare wash of Egyptian blue.

They are produced by `scripts/paint-plates.mjs`, which builds each shape from hand-jittered strokes, roughens and breaks up the pigment, and writes ordinary WebP files. **They are generated by code, not painted by hand.** Each one is a plain image, so a commissioned painting can replace it file for file:

| File | Used for | To swap |
|---|---|---|
| `wall.webp` | Hero: the plaster wall (far layer) | Any 2:1 image |
| `arc.webp` | Hero and site-wide arc (revealed by a mask as you scroll) | A square image of a full ring on transparency |
| `temple.webp` | Hero: the parent temple, with one empty place in the colonnade | Keep the gap where the column stands |
| `column.webp`, `column-sinopia.webp` | Hero: the column that leaves, painted and as an underdrawing | Same canvas size (240 x 640), base 40 px above the bottom edge |
| `site-base.webp`, `site-temple.webp` | Hero: the base that waits, and the temple painted round the column | Keep the centre clear for the column |
| `floor.webp` | Hero: the Greek-key band nearest the viewer | Any wide strip |
| `hero-start.webp`, `hero-end.webp` | First paint while layers load; the still shown under reduced motion | Flattened 16:8 stills |
| `frag-arc`, `frag-columns`, `frag-meander`, `frag-laurel`, `frag-stele`, `frag-teleo` | One fresco fragment per interior page hero. `frag-teleo` is the TELEO T in Egyptian blue and orange ochre (Firm, Team) | 900 x 900 on transparency |
| `meander.webp` | The painted Greek key along the top of the footer | A repeating tile |

Positions of the hero layers are in `src/lib/plates.json` (written by the paint script). If a replacement has different dimensions, edit the entry's `x`, `y`, `w`, `h` there.

## The hero film

`src/components/HomeHero.tsx`. A 560vh scroll track pins the stage. Scroll progress drives:

- the camera: four keyframes (`CAM_DESKTOP`, `CAM_MOBILE`) that pan and push across the painting
- depth: each layer lags or leads the camera (`DEPTH`), plus a small cursor drift
- the carve-out: the column fades to its underdrawing, lifts, travels, and is painted again; the new temple is washed in from the ground up; the arc closes
- the captions I, II, III and the closing statement

"Skip the film" jumps past it. Under `prefers-reduced-motion` the stage shows the finished still and the chapters become a plain list.

## Team photographs

`public/team/`, downloaded from teleocapital.com and shown exactly as supplied: black-and-white, not tinted, cropped or painted over. Each person in `content/data.json` has `photo` (500 x 460, grid and hero) and `bioPhoto` (500 x 640, profile panel). Alt text is "Name, Title". A person without a `photo` is listed with no image; nothing is generated in its place.

## Contact form

`src/components/ContactForm.tsx` posts to `/api/contact` and renders a Cloudflare Turnstile widget, matching the current site. That endpoint is a Cloudflare Pages Function in the existing deployment and is **not in this repo**. Copy the existing `functions/api/contact` function into this project, or the form will show its error message.

## Not included

- Painted figures. The plates are architecture and ornament only; a generated figure did not meet the standard and was left out.
- A favicon. teleocapital.com has no `favicon.ico` to copy and the mark must not be redrawn.
- Google Analytics. The measurement ID is in `content/data.json` (`firm.gaId`) but no tag is loaded.
- Individual press release pages. News items link to their original source.
